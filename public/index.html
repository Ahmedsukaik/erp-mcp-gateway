ERP MCP Gateway · live demo

An AI agent reads order emails and works with an ERP through an MCP server. It can read data and propose changes. Nothing is written to the ERP until a person approves, and every step is in the audit log.

This is a reference build running on a demo ERP with sample data, not a client system. Emails here are read by fixed rules, not an AI model. Your session is private and starts fresh when you reload the page.

  1. 1. Email arrivesPick one from the inbox, or write your own.
  2. 2. Agent reads itIt checks the sender and products with read tools over MCP.
  3. 3. Agent proposesThe order waits in the queue. The ERP is unchanged.
  4. 4. A person decidesApprove or reject. Only then does the gateway write.
